Agent Discovery

blog.init.engineer 代理人探索文件

本頁整理本站目前已公開的機器可讀入口、技能索引、Markdown 備援與瀏覽器端工具能力。 本站本質上仍是內容型靜態網站，主要提供搜尋、導覽與內容探索，不提供受保護 API。

探索入口

API Catalog

/.well-known/api-catalog

列出公開探索 API、OpenAPI 規格、說明文件與狀態端點。

Agent Skills

/.well-known/agent-skills/index.json

提供站點導覽與文章探索技能，方便代理人快速理解本站結構。

Markdown 備援

/.well-known/markdown/home.md

提供首頁的靜態 Markdown 備援版本，便於尚未接上邊緣協商時使用。

MCP Server Card

/.well-known/mcp/server-card.json

描述本站以 WebMCP 提供的瀏覽器端工具能力。

網站中介資料

/api/site-metadata.json

彙整語言、Feed、探索入口與目前支援狀態。

OAuth Metadata

/.well-known/oauth-authorization-server

提供純 OAuth 探索中介資料，明確宣告目前尚未開放授權流程。

內容使用偏好

本站在 /robots.txt 中透過 Content-Signal 宣告以下偏好：

  • search=yes：允許一般搜尋索引與結果摘要。
  • ai-input=no：不允許將內容直接用於即時 AI 回答輸入。
  • ai-train=no：不允許將內容用於模型訓練或微調。

驗證與保護資源

本站目前沒有需要登入的公開 API，因此沒有發布 OpenID Connect 的 /.well-known/openid-configuration。 不過為了讓代理人能機器可讀地確認現況，本站已發布 /.well-known/oauth-authorization-server 與 /.well-known/oauth-protected-resource， 並明確宣告目前尚未提供可用的 OAuth grant flow。 若未來新增受保護 API，會再把這兩份文件替換成實際的授權端點與 scopes。

MCP 與 WebMCP

本站目前沒有獨立的遠端 MCP 伺服器，但已提供一份 MCP Server Card， 用來描述目前由瀏覽器端 WebMCP 暴露的工具集合。 代理人可以在支援 WebMCP 的瀏覽器環境中，直接使用本站的搜尋與導覽能力。

GitHub Pages 限制

純 GitHub Pages 直出無法僅靠靜態檔案完整啟用 HTTP Link 回應標頭與 Accept: text/markdown 內容協商。 因此專案內另外提供可部署的 Cloudflare Worker 設定，當正式網域綁到 Worker 後， 這兩項能力就會由邊緣層接手。
