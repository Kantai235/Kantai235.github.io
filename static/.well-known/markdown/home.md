# 我不會寫程式

歡迎來到 `blog.init.engineer`。

這是乾太（Kantai）的個人網站與技術部落格，主要內容包含：

- 軟體工程與工具開發筆記
- 多語言文章存檔（繁體中文、簡體中文、English、日本語）
- 獸設（Kemono）角色與藝術委託展示
- 個人工程師簡介
