公開探索 API

blog.init.engineer 機器可讀端點

這裡整理本站提供給代理人、搜尋工具與自動化流程使用的公開唯讀端點。 所有端點皆不需要登入，且目前未提供 OAuth / OIDC 保護資源。

主要端點

路徑 用途
/.well-known/api-catalog API Catalog，提供公開探索入口。
/api/site-metadata.json 網站摘要、語言、Feed 與代理人探索連結。
/api/status.json 靜態站點狀態與部署說明。
/openapi/site-discovery.yaml OpenAPI 3.1 規格，描述公開探索端點。
/.well-known/agent-skills/index.json Agent Skills Discovery 索引。
/.well-known/agent-card.json A2A Agent Card，提供代理人對代理人的 discovery 描述。
/.well-known/markdown/home.md 首頁的 Markdown 備援版本。
/a2a 實驗性 A2A JSON-RPC discovery 入口，目前用於宣告服務位置與回應未實作狀態。
/index.json Hugo 產生的站內搜尋索引。
/sitemap.xml 網站地圖。
/index.xml RSS Feed。

補充說明

本站目前以 GitHub Pages 發佈，因此像是 HTTP Link 回應標頭與 Accept: text/markdown 的內容協商，需要額外的邊緣層代理才能真正生效。 專案內已提供對應的靜態探索檔與部署範本，方便後續掛到支援自訂標頭的平臺。
